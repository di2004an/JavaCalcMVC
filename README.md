# Калькулятор MVC (Практическое задание)

Программа представляет собой консольное приложение-калькулятор на языке Java, построенное по шаблону проектирования MVC.

## Структура приложения
- **CalculatorLogic (Model):** отвечает за математику (exp4j), логику сохранения и экспорта истории.
- **TerminalUI (View):** отвечает за отрисовку консольного меню и получение ввода от пользователя.
- **AppLogicController (Controller):** маршрутизатор команд.
- **ApplicationRunner:** инициализация слоёв и запуск.

## Системные требования и сборка
В проекте используется сборщик **Maven**. Ядром вычислений служит библиотека `exp4j` (версия 0.4.8). 

**ИНСТРУКЦИЯ ПО ЗАПУСКУ:**
1. Откройте проект в IntelliJ IDEA.
2. В обязательном порядке обновите зависимости Maven (Кнопка `Reload All Maven Projects`), иначе библиотека не скачается и проект не запустится.
3. Запустите метод `main` в классе `ApplicationRunner`.
